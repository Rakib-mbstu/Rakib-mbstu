`React` `Node.js` `JavaScript` `REST API` `JWT`

### 🎓 [Student Management System](https://github.com/Rakib-mbstu/Student-Management-System)
A full CRUD web application for managing student records, course enrollment, and grades. Leverages Spring Data JPA for persistence and Thymeleaf for server-side rendering.
`Spring Boot` `JPA` `Thymeleaf` `HTML`
